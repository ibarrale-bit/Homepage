    • Entry #1 (8/20/2026)

    Laurel Schultz's interpretation of a website relies on the fact that it’s crafted for a specific individual/group. This is done by using different metaphors, relating websites to gardens, shelves, or even puddles. Despite the fact that all websites are archival in some way, this explanation shows that websites can be multiple things. Ursula K. Le Guin enforces that technology can be anything that humans learn how to use or make. Websites can be one, as they are active human archivals full of information and graphics that we have all learned or want others to learn about.

    Entry #2 (9/1/2026)

    A big thing that J.R. Carpenter focuses on how in a website, the medium in which the visuals are displayed is completely uniform. This differs from physical archivals, such as museum galleries. However, that does not take away the complexity of web-making, specifically hand-made websites. Websites are like individual collections, galleries made for and by the singular person.

    J.R. Carpenter uses the term Handmade Web to describe how the slow creation and building up of a website represents human engagement, creativity, and resistance to automation. This resonated with me, because despite the fact that a website is always digital, it reminds us that digital mediums can still be crafted using our individualistic ideas and skillset.
